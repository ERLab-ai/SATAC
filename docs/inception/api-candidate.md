# SATAC Public API — candidate 0.1
P0/P1 technical review candidate, no phase closure or deployment. FastAPI + psycopg on PostgreSQL/PostGIS. Public read only, no internal write routes. Apply 0001 then 0002 in a disposable database. Provision an independent LOGIN role with only satac_reader membership, set SATAC_READER_DSN outside source control, install apps/api/requirements.txt and run python -m uvicorn apps.api.main:app --host 127.0.0.1 --port 8000. The service rejects elevated credentials; this is not a full security audit.

Routes: GET /health, /api/v1/releases, /api/v1/claims/{claim_id}, /api/v1/relations (one-hop), /api/v1/map/features (GeoJSON). OpenAPI at /docs and /openapi.json. Query as_of or from/to uses integer astronomical years represented by decimal strings to avoid JavaScript rounding; certainty any includes possible and certain; undated excluded from dated queries. Explicit release required on subsequent keyset pages (version UUID); withdrawals may remove rows even from old releases. A read-only repeatable-read transaction pins each request to one DB snapshot. Historical hashes describe original snapshots, not current withdrawal overlay. Bbox crossing the antimeridian is split into two envelopes; input geometries must already be normalized. Exact geometric intersection, not uncertainty envelope. Map pages are by claim, not feature. Query uses public JSON snapshots; spatial filter scans snapshot geometry and does not use the private GiST index; no A13 performance claim.

Only public views and the public temporal-match helper are accessed. No draft or review status response fields. Public error responses omit database diagnostics. No user authentication, pool, full Arabic name search, entity detail, source route, graph traversal, generic typed claims, staging API, public deployment or legacy migration yet. Dependency pins are direct, not a fully resolved lock. CI runs HTTP integration tests with TestClient and an actual isolated PostGIS database, including an elevated-login rejection test. Invented fixtures are strictly disposable, not public datasets.
