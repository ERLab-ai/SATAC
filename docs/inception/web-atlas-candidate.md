# Web atlas — technical candidate 0.1
Arabic-first React/TypeScript/Vite/MapLibre, connected to the public read API; not a production release or phase closure. Start the read-only API on 127.0.0.1:8000 with a reader DSN, then cd apps/web, npm install, npm run dev. Build with npm run build, preview with npm run preview. Vite proxies relative /api requests to the local API in dev/preview; deployment requires same-origin routing. CI browser tests use the actual PostGIS database and published three-place legacy sample, not a static mock.

The land backdrop is the MultiPolygon from baseline v0.13 data/basemap.json (commit 46a48ec5bd3656b2c514458d1637358a28664088, blob ebb1db5a7e4df239b6c07e5f328339ec1e3658f0); no historical or political boundaries inferred. No remote tile provider or fonts. Map reads whole-world GeoJSON (Mercator latitude +/-85), up to 10 pages of 200 claim rows, with explicit truncation notice. Supports release selection, year BCE/CE with BigInt and Arabic digit conversion, time certainty, search with keyset pagination, keyboard-accessible list fallback, entity names, scientific note and available references. Missing dates are excluded by dated filters; no dates invented for the sample. No review badges, administrative data or write endpoints.

Direct dependency pins only until lockfile is generated and checked in; no performance/WCAG certification. No historical timeline slider, full encyclopedia, relation graph, viewport-index optimization, all legacy data migration, production authentication, deployment or complete P1 acceptance. The candidate has a responsive layout but requires broader accessibility and device review.

Immersive iteration: dark v0.13-derived palette, full-width map, floating mutually exclusive search/knowledge panels, actual map point labels (up to 100 features), location toggle, region/world view, scale, bottom year navigation and playback. Year steps use astronomical integers across BCE/CE; no inferred dates. This is partial visual/interaction parity only. See parity register.

Physical geography iteration: exact legacy geography.json SHA-256 verified before generation. Two 512px XYZ raster pyramids z0–2 (21 tiles each), from original shaded-relief and ETOPO images, not elevation samples. Scale-dependent reference labels preserve all 91 original records; modern city labels hidden when dated filter active. Generate assets before Vite build/dev: install pipelines/legacy_geography/requirements.txt in a separate Python environment then run python pipelines/prepare_web_geography.py. Optional --legacy-geography points to the original verified JSON. Build outputs are ignored; CI rebuilds and uploads them. Overzoom is not higher resolution; no terrain mesh or historical landscape reconstruction. Browser test includes desktop/mobile screenshots. Original source: baseline/v0.13 prepare_geography.py blob fb3c299e72e44104fa6fb339bfa305fb6f3f8576.

Regional visual grid and rivers: build verifies original worldtiles SHA-256 4c8e268ba75045b73be09b4f2bcabffd955479493b5a6a7bbee4fc21b212b0ed in addition to geography SHA. Inverse legacy equirectangular projection (lon=x*360/1000-180, lat=90-y*180/500) preserves rounded original geometry/color. 37,209 cells (23,952 land-centered) are regional, not global or equal-area; original texture residual and 2,480 analytical cells not yet migrated. 9,325 world and 1,848 regional river path segments, not counts of unique rivers; switched by zoom, reference geography not historical hydrology. Minimap uses original land and actual camera bounds, pointer navigation and keyboard-accessible world reset. Both original JSON files required for optional local generation. No invented geographic facts. Browser tests verify asset counts and controls, not cartographic visual certification.
