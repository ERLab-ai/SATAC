# Entity names and Arabic search — candidate 0.1

P0/P1 review candidate, no phase closure. Migration 0003 adds NAME typed text claims (Arabic/English), release-scoped name view, deterministic crosswalk and search normalization. Name claims share immutable release snapshots and withdrawal policy. Search folds Arabic alef variants, alif maqsura, common diacritics and tatweel, NFKC and lowercase; original labels unchanged. No automatic entity merge, stemming, fuzzy matching or morphology. Search returns matching name claims (not deduplicated entities) with stable UUID keyset pagination; explicit release on later pages. Temporal filters exclude undated names. Entity endpoint gives published names, not a complete encyclopedia page.
