# A07 — Embedded source access candidate

The owner policy v1.2 controls distribution. This is an explicit curator operation, not a licensing decision. Ordinary evidence-only source masking remains independent. revoke_embedded_source withholds structured legacy claims whose immutable snapshots reference the selected source version, and masks the reference in ordinary claims. Whole-record withholding avoids invalid partial JSON in dependent readers. All release-scoped projections inherit the decision; stored release members and hashes remain unchanged. No actual restriction has been applied.

Limitations: references not represented in snapshots, embedded URLs/prose, aliases and static geography/art require separate provenance mapping and controls. No automatic withholding based on missing sources. Future exports must use the same public projection. A07 remains incomplete until these controls and end-to-end regressions are verified.
