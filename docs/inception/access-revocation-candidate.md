# Selective public access revocation
Reopened policy v1.2, migrations 0011–0012 and live API query code. Prior release integrity CI 46023832001 passed both jobs (81 Python + 19 browser tests plus SQL). Migration 0013 adds append-only curator-controlled source and geometry revocation. A source version UUID is masked from structured references across all claims/releases, including later carry-forward; a source's existing restricted flag is also honored on public reads. Geometry revocation selects a one-based index in the private stored release's geometry array, hashes the exact stored GeoJSON, and masks all identical geometry values within the specified claim version across releases (regardless of role/precision). It never guesses from mutable staging. Different geometries or different claim versions are independent, even if geographically close. Whole-version access withholding uses the existing immutable withdrawal table but does not create an incorrectness/correction task. It is the conservative mechanism for embedded literal coordinates, article bibliographies, routes, snapshots, geology, cells and other fields not represented as structured references or attestations. No automatic text redaction or dependency cascade by source identity; curators must identify affected embedded records and derivative data separately. Existing static geographic assets are outside this database overlay. Public release_claims security-barrier view applies the mask before all existing derived views, map bbox and search; stored payloads, manifest and history unchanged. A previously downloaded/cached copy cannot be recalled; deployment cache invalidation and client refresh remain separate. No public access to audit reasons/actors, no API write endpoint, no automatic rights determination. Explicit curator revocations are permanent in this candidate; future authorized replacement uses new version IDs. Restricted flag alone is mutable staging policy, not permanent revocation. SQL regression uses rollback; HTTP test executes after browser suite on disposable database and restores test pointer.
