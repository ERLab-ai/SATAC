## Security
Existing reader uses repeatable-read read-only transactions, parameterized SQL, private schema denial and sanitized validation/DB errors. Additional guard rejects any membership of PostgreSQL predefined pg_ roles, even if the account has no knowledge schema USAGE and no superuser flag (conservative dedicated-reader contract). Add Cache-Control no-store to handled API success/error responses because old releases may later be masked. Add nosniff, DENY framing, no-referrer and same-origin resource policy. No CORS grant or public mutation route. Tests for direct private access/write rejection, predefined role failure and recovery, handled errors and missing DSN. Middleware does not certify all upstream proxy or unhandled 500 responses.
Preview-only Vite HTTP CSP restricts local scripts/network/images/workers, permits blob workers/data images and inline styles required by MapLibre/React; denies plugins/framing and base URI changes. Permissions-Policy denies camera/mic/geolocation/payment. Development server unchanged. Production reverse proxy must apply equivalent policy, TLS, rate limits, request limits, logs, secret provisioning and caching rules; preview is not a production server. No dependency vulnerability scan, external penetration test, secret rotation or TLS validation in this change.
