# السعودية عبر الزمن، عبر القارات — SATAC v0.13

افتح `index.html` في متصفح حديث. جميع البيانات المضمنة تعمل محليًا. اختر «جيولوجيا الأرض» من الشريط العلوي، ثم فعّل أو أخفِ الأقاليم والحرات، وحدد نوع الإقليم أو الفترة البركانية. انقر على الخريطة أو ابحث عن حرة رهط أو الدرع العربي. من «الأرض والموارد» اختر خلية لفتح الأقاليم المتقاطعة معها. الطبقات الجيولوجية مرجعية معاصرة لا تعيد بناء الأرض في العصور القديمة.

## التطوير
`python prepare_geology.py && python build.py`

`pytest -q tests/test_geology.py tests/test_cells.py`

يتطلب إعادة البناء Python وShapely، وتشغيل الاختبارات Playwright وChromium. لا يلزم تثبيت هذه الأدوات لمجرد فتح HTML.

[التقرير الفني والمصادر والقيود](docs/GEOLOGY_RELEASE_AR.md) · [نتائج الاختبارات](docs/test-results-v013.txt)

تتضمن الحزمة وظائف وبيانات الإصدارات السابقة، لكن اختبار الانحدار الشامل لهذه الدورة لم يكتمل. البيانات الجيولوجية مبسطة وليست خرائط احتياطيات، والمشروع نموذج محلي بحثي غير معتمد للنشر العام. راجع ملفات التراخيص وتقارير الإصدارات السابقة.
